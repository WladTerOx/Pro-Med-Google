## ✨ Возможности

### 🤖 Локальный ИИ Ollama

- **Полностью локальная обработка** - все ИИ-функции работают без облачных сервисов
- **Многоязычная поддержка** - перевод запросов и результатов
- **Автономная работа** - не зависит от внешних API

### 🔍 Умный поиск

- **Оптимизация запросов** - ИИ автоматически сокращает длинные запросы до ключевых терминов PubMed
- **Многострочный ввод** - поддержка длинных, детальных описаний проблем
- **Автоперевод** - автоматический перевод с русского на английский для PubMed

### 📱 Современный интерфейс

- **Адаптивный дизайн** - отлично работает на всех устройствах
- **Темная тема** - комфортное использование в любое время суток
- **Интуитивный UX** - простая навигация и понятные элементы управления

### 🎯 AI-функции

- **Перевод заголовков** - автоматический перевод английских заголовков на русский
- **Простой язык** - объяснение сложных медицинских терминов простыми словами
- **Оптимизация поиска** - извлечение ключевых медицинских терминов из длинных текстов

## 🚀 Быстрый старт

### Предварительные требования

- **Node.js** 18+
- **Ollama** установлен и запущен
- **Модель ИИ** загружена (рекомендуется `gpt-oss:20b-cloud`)

### Установка и запуск

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/VladTer06081963/Pro-Med-Google.git
   cd pubmed-ai-explorer
   ```

2. **Установите зависимости:**

   ```bash
   npm install
   ```

3. **Настройте переменные окружения:**
   Отредактируйте файл `.env.local`:

   ```env
    # Ollama Configuration (Local AI)
    VITE_OLLAMA_BASE_URL=http://192.168.50.250:11434
    VITE_OLLAMA_MODEL=gpt-oss:20b-cloud

   # Optional: PubMed API Key для увеличения лимитов запросов
   GEMINI_API_KEY=your_key_here
   ```

4. **Запустите Ollama:**

   ```bash
   ollama serve
   ```

5. **Загрузите модель:**

   ```bash
   ollama pull gpt-oss:20b-cloud
   ```

6. **Запустите приложение:**

   ```bash
   npm run dev
   ```

7. **Откройте в браузере:**
   ```
    http://localhost:3009
    ```

## 🐳 Production Deployment

Для production-развёртывания с Docker, Traefik и pm2:

### Предварительные требования
- Docker и Docker Compose
- Traefik с SSL-сертификатами
- WireGuard VPN для доступа к Ollama
- pm2 для управления процессами

### Настройка
1. **Соберите проект:**
   ```bash
   npm run build
   ```

2. **Настройте Docker Compose:**
   Убедитесь, что `docker-compose.yml` в `/root` включает сервис med-proxy.

3. **Запустите с pm2:**
   ```bash
   pm2 start ecosystem.config.js
   pm2 save
   ```

4. **Доступ:**
   - Frontend: https://med.openaiua.cloud (через Traefik)
   - Ollama: Через WireGuard на 192.168.50.250:11434

### Настройка WireGuard
- Подключитесь к VPN для доступа к Ollama.
- Убедитесь, что Ollama сервер запущен на удалённой машине.

### Мониторинг
- `pm2 monit` для мониторинга процессов
- `docker-compose logs` для логов контейнеров

## 📖 Использование

### Поиск статей

1. **Введите запрос** на русском языке в текстовое поле
2. **Используйте многострочный ввод** для детальных описаний
3. **Нажмите "Найти"** - ИИ автоматически оптимизирует и переведёт запрос
4. **Просмотрите результаты** с переведёнными заголовками

### Работа с длинными запросами

Приложение автоматически распознаёт длинные запросы и оптимизирует их:

```
Длинный запрос:
"Я ищу исследования о влиянии употребления кофе на сердечно-сосудистую систему у пожилых людей с диабетом 2 типа"

Оптимизированный запрос:
"coffee cardiovascular diabetes elderly myocardial infarction stroke prevention"
```

### Просмотр статей

- **Нажмите "Пересказать (AI)"** для объяснения статьи простым языком
- **Используйте "Очистить"** для сброса поиска
- **Переключайте тему** с помощью кнопки луны/солнца

## 🛠 Технические детали

### Архитектура

```
src/
├── components/          # UI компоненты
│   ├── Icon.tsx        # SVG иконки
│   └── ArticleModal.tsx # Модальное окно статьи
├── services/           # Сервисы ИИ
│   ├── ai.ts          # Абстракция ИИ (экспорт функций)
│   ├── ollama.ts      # Ollama API интеграция
│   └── pubmed.ts      # PubMed API клиент
├── types.ts           # TypeScript типы
├── App.tsx            # Главный компонент
└── index.tsx          # Точка входа
```

### ИИ функции

#### `translateQueryToEnglish(query)`

Перевод поисковых запросов с русского на английский для PubMed

#### `translateTitlesToRussian(titles[])`

Перевод массива заголовков статей на русский

#### `optimizeQueryForPubMed(longQuery)`

Оптимизация длинных запросов до ключевых терминов PubMed

#### `summarizeArticleForLayperson(title, abstract)`

Простое объяснение медицинской статьи на русском языке

### Переменные окружения

| Переменная             | Описание                              | Значение по умолчанию    |
| ---------------------- | ------------------------------------- | ------------------------ |
| `VITE_OLLAMA_BASE_URL` | URL Ollama сервера                    | `http://localhost:11434` |
| `VITE_OLLAMA_MODEL`    | Название модели Ollama                | `gpt-oss:20b`            |
| `GEMINI_API_KEY`       | Ключ для резервного API (опционально) | -                        |
