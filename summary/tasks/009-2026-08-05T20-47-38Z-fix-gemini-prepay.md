# 009 — Восстановить работу Gemini (prepay исчерпан или нужен новый ключ)

**Создан:** 2026-08-05 20:47 UTC
**Приоритет:** 🔴 высокий
**Связано с:** audit/001 (Gemini 429 RESOURCE_EXHAUSTED)

## Проблема

Текущий Gemini-ключ `AIzaSyCtQie1lOG4ONs_6L_Rr1X2bMwJbTK06Qs` валиден, но prepay-кредиты исчерпаны:

```
HTTP 429
"Your prepayment credits are depleted. Please go to AI Studio at
 https://ai.google.dev/gemini-api/docs/billing#prepay to manage your project and billing."
```

Без второго провайдера весь объём переводов и суммаризаций падает на Mistral.

## Что сделать

**Вариант А:** пополнить prepay для текущего проекта в AI Studio.

1. Открыть https://aistudio.google.com/projects (или https://ai.google.dev/gemini-api/docs/billing#prepay).
2. Найти проект, к которому привязан ключ `AIzaSyCtQie1lOG4ONs_6L_Rr1X2bMwJbTK06Qs`.
3. Привязать платёжный аккаунт / пополнить баланс.

**Вариант Б:** получить новый ключ с активным биллингом.

1. В AI Studio → API keys → Create API key in new project.
2. Скопировать ключ.

**После получения ключа (любой вариант):**

1. Обновить `/root/Projects/Pro-Med-Google/.env` и `/root/Projects/Pro-Med-Google/key/.env.local`:
   ```
   VITE_API_KEY=<новый ключ>
   ```
2. `npm run build` → деплой.

## Где

- https://aistudio.google.com/projects
- `/root/Projects/Pro-Med-Google/.env`
- `/root/Projects/Pro-Med-Google/key/.env.local`

## Зачем

- Два облачных провайдера (Gemini + Mistral) = устойчивость к лимитам/сбоям одного из них.
- Gemini 2.5 Flash — быстрее и дешевле Mistral для коротких задач.

## Acceptance criteria

- `curl "https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=<новый>" -d '{"contents":[{"parts":[{"text":"Reply: OK"}]}]}'` → HTTP 200, `"OK"` в ответе.
- В UI при выборе провайдера Gemini — перевод/суммаризация работают.
