# 008 — Поднять Ollama или сменить VITE_OLLAMA_BASE_URL

**Создан:** 2026-08-05 20:47 UTC
**Приоритет:** 🔴 высокий (но требует инфраструктурного решения)
**Связано с:** audit/001 (Ollama недоступен)

## Проблема

Оба Ollama-хоста недоступны с этого сервера:

| URL | Источник | Статус |
|-----|----------|--------|
| `http://162.19.248.57:11434` | `.env` (`VITE_OLLAMA_BASE_URL`) | ❌ connection timeout |
| `http://192.168.50.250:11434` | fallback в `services/ollama.ts` | ❌ connection timeout |

Без Ollama приоритет в `services/ai.ts` сразу падает на Gemini (429) → Mistral (работает). Пользоваться можно, но:
- Вся нагрузка ложится на Mistral (расход токенов, риск лимитов).
- Локальная приватность теряется — медицинские запросы уходят в облако.
- `192.168.50.250` — приватный IP, захардкожен в коде (см. задачу 011).

## Что сделать

Сначала выяснить, что **должно** быть:

1. Спросить у владельца: где физически живёт Ollama? Это:
   - тот же сервер (тогда `http://localhost:11434`)?
   - отдельная машина в локальной сети?
   - VPN/туннель?

2. Проверить сетевую доступность:
   ```bash
   nc -zv 162.19.248.57 11434    # с этого сервера
   nc -zv 192.168.50.250 11434   # с этого сервера
   ip route get 162.19.248.57
   ```

3. Если Ollama должна быть локально — установить на этом сервере:
   ```bash
   curl -fsSL https://ollama.ai/install.sh | sh
   systemctl enable ollama
   ollama pull gemma2:2b    # модель из .env
   ```

4. Обновить `.env`:
   ```
   VITE_OLLAMA_BASE_URL=http://localhost:11434
   ```

5. Если Ollama на отдельной машине — обновить URL и проверить маршрутизацию/firewall.

6. `npm run build` + `./deploy.sh` (см. задачу 005).

## Где

- `/root/Projects/Pro-Med-Google/.env` — `VITE_OLLAMA_BASE_URL`.
- Возможно, инфраструктура (установка Ollama, firewall).

## Зачем

- Снизить нагрузку на облачные API (Mistral, Gemini).
- Обеспечить приватность медицинских запросов.
- Получить первый приоритетный провайдер (быстрее, дешевле).

## Acceptance criteria

- `curl http://<новый-URL>:11434/api/tags` возвращает 200 OK.
- `services/ai.ts` в браузере при выборе Ollama показывает «Ollama доступен».
- Перевод RU→EN через Ollama возвращает результат без обращения к облаку.
