## Известные риски и gotchas

* **R1:** Версия `@modelcontextprotocol/sdk` фиксируется на `~1.24.0`.
* **R2/R4:** Логика AI-оркестратора дублируется в Node-модуле MCP для независимости от Vite (`import.meta.env`); вынос в общий пакет `packages/ai-core` запланирован как follow-up task 15.4.
* **R5:** Публичный роутер `mcp.openaiua.cloud` защищается только по Bearer-токену (без Basic Auth).
